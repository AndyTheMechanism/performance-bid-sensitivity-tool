# Инструмент аудита эффективности и анализа чувствительности ставок

## 📊 Обзор проекта
Этот проект демонстрирует тактический подход к маркетинговой аналитике с использованием стека **PostgreSQL + Power BI**. Сырая выгрузка из **Яндекс Директа** (B2B сегмент, более 260 тыс. строк) преобразуется в интерактивный инструмент для оптимизации ставок и аудита креативов.

### Ключевые особенности:
* **ETL на базе SQL:** Очистка данных и расчет метрик (CPC, CPP, CR) на уровне базы данных для обеспечения высокой производительности.
* **Валидация данных (QA):** Автоматическое обнаружение и удаление технических аномалий (например, «фантомных» кликов при 0 показов).
* **Анализ чувствительности ставок:** Интерактивный параметр «What-if», позволяющий динамически устанавливать пороги целевого CPC.
* **Система визуальных алертов:** Матричный индикатор «Светофор», подсвечивающий неэффективные кампании в режиме реального времени.

## 🛠️ Технологический стек
* **База данных:** PostgreSQL (Хранение и трансформация).
* **BI-инструмент:** Microsoft Power BI (режим Import).
* **Языки:** SQL (PostgreSQL), DAX (Продвинутое моделирование).
* **Методология:** Валидация данных, семантическое моделирование, анализ чувствительности.

---

## 🚀 Архитектура проекта
1.  **Извлечение:** Сырые CSV-данные (260к+ строк ежедневной статистики).
2.  **Инженерия (SQL):** * Настройка схемы и импорт данных.
    * Очистка «фантомных кликов» (удалено 14 строк).
    * Создание аналитического представления (View) для корректных расчетов.
3.  **Визуализация (Power BI):** * Подключение к PostgreSQL View.
    * DAX-меры для исключения ошибки «среднего от средних».
    * Интеграция What-if параметра для динамического управления порогами KPI.

---

## 🧠 Аналитические выводы
Использование **слайсера Target CPC** позволяет наглядно увидеть, как снижение максимальной ставки на 10% отсекает дорогостоящие сегменты с высоким CPP. Это дает возможность проводить «хирургическую» оптимизацию бюджета, сохраняя объем конверсий в прибыльных нишах.
